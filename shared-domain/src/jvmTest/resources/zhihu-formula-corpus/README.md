# 知乎真实公式正文语料

本目录保存公开知乎内容的公式索引，供 `ZhihuFormulaCorpusTest` 离线验证应用当前依赖的 LaTeX 解析器。公开来源、哈希、作者和公式数量以 `manifest.json` 为准，不在本文重复维护采集清单。

- `manifest.json`：内容来源、哈希和数量；
- `formulas.json`：从原始正文派生的去重 LaTeX 公式及来源；
- `katex-ast-oracle.json`：固定版本 KaTeX 生成的解析语义基准，维护入口见 [基准生成工具](../../../../../tools/katex-ast-oracle/README.md)。

公式索引与解析语义检查不代表完整 HTML 正文重放。完整原始响应不随仓提供；需要重放时，在 [外部隔离验证树](../../../../../docs/testing-maintenance.md) 提供与清单哈希匹配的获准资源与验证代码，不提交原始响应或凭据。

刷新语料是显式维护操作，普通测试不联网采集。保留原始公式、转义和来源关系，不为通过解析而改写样本；候选发现记录、账号信息和登录凭据不属于公开语料。
