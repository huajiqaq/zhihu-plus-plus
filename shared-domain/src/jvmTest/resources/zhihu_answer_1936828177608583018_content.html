语言是好语言，用过 Kotlin 后，就再也不想回去使用 Java，不愧是搞 IDE 公司设计出来的语言，太懂程序员的痛点了。

以下是我想到的一些让我非常舒服的语言设计


看到 Int、Float……这些，再回去看看 Java 的 int-Integer、float-Float，这一套总觉得哪不对味。


在看看Any，Any？，Nothing，Nothing? 这一套继承体系，第一次了解完这些概念后，就觉得类型系统就应该这样设计，从语言层面统一，没有例外情况，看上去就舒舒服服。


函数默认返回Unit , 而不是 void，前者是一个普通类罢了。


一切皆是表达式，意味我们可以写出这样的代码，使得某些逻辑表达更为容易

val foo = if (a) b else c

val bar = try { a } catch (_: Exception) { b }

不强制 Check Exception。


无缝兼容 Java，这意味着有庞大的生态，然后大量老旧Java代码也不用抛弃重写。


大量默认的不可变设计，大量减少副作用，val, listOf(), 唯一的抱怨是 val 和 var 不太容易区分，把 val 替换成 let 不知道会不会更好。


对 lambda 支持，可以看看 Compose 设计，在 Java 上几乎不可能设计出这样的类库。


缺点：
除了 Android 上，好像其它领域没啥人用，跳槽不友好。


梦想中语言


要是有一门语言，语言设计像 Kotlin 这样，然后编译后产物像 Go 那样，单个可执行文件，简洁无依赖。就太妙了。我非常喜欢 Go 的一些东西，比如编译快，源码依赖，单个小小的无依赖的可执行文件，但 Go 语言设计实在是太大道至简了。写起来实在是不舒服。
