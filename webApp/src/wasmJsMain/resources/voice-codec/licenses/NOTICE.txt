ffmpeg.wasm single-thread core 0.12.10

The unmodified UMD JavaScript and WebAssembly binaries are supplied by the
@ffmpeg/core 0.12.10 npm package. They are loaded locally only when recording
needs transcoding. No CDN, multi-thread core, or SharedArrayBuffer is required.

The npm package declares GPL-2.0-or-later for the compiled core. This is not
the MIT license of @ffmpeg/ffmpeg (that wrapper is not included). The actual
compiled FFmpeg core enables GPL components, including x264 and x265.
Each third-party component retains the copyright, license and patent notices
in its own directory. FFmpeg's upstream license explanation is preserved in
ffmpeg/LICENSE.txt; the original filename was LICENSE.md.

sources.json lists the source revision and original licenses for all external
libraries selected by that Dockerfile, plus the SDL2 and Emscripten runtimes.
The release recipe names x264's 4-cores branch and LAME's master branch; the
recorded commits are their unchanged heads before publication, not a claim
that the upstream binary provides a separate reproducible-build attestation.
The upstream v0.12.10 Git tag names an older wrapper/core combination and is
NOT the source reference for @ffmpeg/core 0.12.10.
