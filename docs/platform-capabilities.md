# 平台能力与边界

这里区分源码接入、产品取舍、平台限制、未实现功能和部署条件；源码或未签名制品存在不代表运行验收或发布已经完成。构建与包内资源检查以对应提交的 CI 结果为准，不能代替 PDF 排版、离线模型推理、系统交互及权限等行为验收。

## 包型与共有缺口

- **移动端 Lite**：Android Lite 与 iOS Lite 使用相同的功能取舍，不含离线 NLP（语义推理、HanLP 自动抽词）和可选 Miuix 皮肤，提供 Material。共享导航、布局及玻璃组件可继续使用 Miuix 相关依赖，不等于移除全部 Miuix 组件。Lite 的产品取舍不表示操作系统不能运行这些功能。
- **Full**：Android Full 接入离线语义过滤；iOS Full、JVM、macOS 原生和 Web 的推理接入仍待验收。PC（Windows、Linux、macOS）默认 Full；Web 按 Full 功能装配，不因此获得原生宿主的权限或后台能力。
- **自动抽词与未实现缺陷**：JVM 的首页卡片“按关键词屏蔽”已接 HanLP 候选提取和 MMR 排序；关键词管理中的自动提取、自动本地推荐尚未接通，结果仍需运行验收。Apple 原生和 Web 的自动关键词提取尚未移植。已有 embedding 语义匹配不等于具备自动抽词，依赖它的本地推荐不能直接视为与 Android Full 等价。尚未移植的部分是实现缺口，不是平台没有 NLP 能力。
- **模型条件**：非 Android 的离线语义过滤由用户主动下载并加载固定版本模型与 tokenizer，约需 407 MB 下载空间，推理另需足够内存。首次下载需联网；网络、校验、存储或运行库加载失败时不能视为模型就绪。不会上传待过滤正文进行云端推理。
- **阅读引擎**：提椠仅有 Android/JVM 制品；Apple 原生和 Web 使用有对应平台制品的 HRM，不把缺少特定引擎制品写成整个平台无法阅读。
- **部署与发布**：AIGC 标记默认关闭；Web 所需独立服务 CORS 改动仍待部署。签名 IPA、签名 MSIX 和 App Store 发布尚未完成。构建入口只说明如何生成制品，不是线上服务、可安装包或商店发布的证明。

## Android

- **宿主**：Android APK，Full / Lite；最低系统与分变体构建方式见 [Android 构建](kmp-android-variants.md)。Lite 不包含 NLP，Full 模型需加载后才能执行语义过滤。
- **PDF**：已接入 WebView 文本排版和 Android `PrintManager`。用户在系统打印界面选择“另存为 PDF”或其他打印目标；不是把正文长图包进 PDF。应用观察打印任务状态，但不取得用户保存位置的文件所有权，不能把打开打印界面当作文件已保存。
- **系统条件**：朗读需要系统可用音色；录音、照片保存及通知按系统版本申请相应权限。系统通知使用 WorkManager，检查时间受联网、节电与系统调度约束，不保证即时送达。
- **待验收**：PDF 的中文、图片、公式、链接、分页、取消和最终交付需在实际系统打印服务中确认；已有源码不代表这些路径通过。

## Windows

- **宿主**：x64 JVM，默认 Full。MSI 与 MSIX 内含 Java 运行时，用户无需另装 Java。Windows 原生 UI 和完整依赖链尚未接成独立目标，这是项目实现缺口。
- **PDF 与 NLP**：JVM PDF 使用 OpenHTMLToPDF / PDFBox 和随包字体生成可选择文本的分页文件，不依赖系统打印机。NLP 使用 ONNX Runtime；当前 Windows JVM 推理运行库仅支持 x64。
- **通知安装条件**：正式 MSI 必须通过仓库打包脚本完成 per-user 安装注册；直接运行 JAR、复制应用目录或其他未注册安装包不能替代。可选 MSIX 必须正式签名并安装。实现与安全要求见 [Windows 通知](../desktopApp/windows/README.md)。
- **分享交付**：系统分享传递文本、链接或真实图片文件，复制是独立操作；选择系统接收方不代表接收方已经完成发送。
- **生命周期**：只在进程运行时检查新消息；已投递通知可按已注册宿主处理冷点击，退出后不会继续抓取。通知权限、勿扰和窗口策略可能阻止呈现或聚焦。
- **待验收与发布**：MSI 安装注册、正式签名 MSIX、通知冷/暖点击、系统文件分享、录音，以及 PDF 和 NLP 的打包运行仍待实际环境验收；unsigned MSIX 不是可用的正式分发包。

## Linux

- **宿主**：x64 JVM AppImage，默认 Full，内含 Java 运行时。Linux 原生 UI 和完整依赖链尚未接成独立目标。
- **PDF 与 NLP**：使用与其他 JVM 宿主相同的文本分页 PDF 和 ONNX Runtime 接入。推理运行库可支持的架构不代表项目已经提供对应架构的 AppImage。
- **运行条件**：音频依赖可用音频服务；朗读需要宿主安装、启用 Speech Dispatcher 并配置语音后端（例如 `speech-dispatcher-espeak-ng`）。AppImage 只携带客户端依赖，不包含或自动启动语音服务。
- **通知与分享**：通知需要可连接的用户会话 D-Bus 和支持 actions 的 `org.freedesktop.Notifications` 服务；退出应用后不能恢复该点击入口。Linux 没有跨桌面统一系统分享选择器，保存或打开文件不等于系统附件分享。
- **待验收**：不同桌面环境的通知动作、音频、录音权限、PDF 排版与模型加载/卸载仍需实际环境验证。

## macOS

- **宿主**：arm64 原生 `.app`，最低 macOS 14；另有 JVM `.app` 构建入口，均默认 Full。原生与 JVM 的渲染、导出、运行库和最低系统要求不同，不能用一端结果代替另一端验收。
- **PDF**：原生宿主通过 WebKit 生成保留文字和矢量内容的连续单页 PDF，不是 A4 分页；JVM 宿主使用文本分页 PDF。两者都不是长图转 PDF。
- **NLP**：原生 arm64 接入 ONNX Runtime C API，要求 macOS 14 或更高版本；JVM NLP 要求 macOS 13.4 或更高版本，支持 Intel / Apple Silicon JVM。运行库支持某架构不等于已经发布对应安装包；打包须保留运行库、资源和许可证。
- **系统条件**：朗读、录音、文件保存与系统分享使用系统 API，需相应许可；分享交给用户选择的接收方，不把复制链接或选择接收方报告成发送完成。JVM 系统通知要求具有有效应用标识的真实 `.app`，直接运行 JAR 不等价；原生与 JVM 只在应用可运行时检查新消息。
- **待验收与发布**：权限拒绝、音频中断、分享交付、通知点击、两套 PDF 路径和 NLP 运行库打包仍待验收。JVM CI 包的 ad-hoc 签名不是正式签名或公证；不能据此宣称已完成公开分发。

## iOS

**验证状态：因设备及验证环境条件限制，本轮未验证 iOS，也未运行对应构建 CI。** 保留源码、Full/Lite 构建入口和验收流程；不得以旧构建记录代替当前版本的验收，也不据此认定已有失败由设备故障造成。

- **宿主与包型**：arm64 设备及 arm64 模拟器，Full / Lite。Lite 与 Android Lite 的功能限制一致，不包含 NLP 和可选 Miuix 皮肤；Full 的离线 NLP 接入仍待 CI 与运行验收。构建及隔离验收方法见 [iOS 宿主](../iosApp/README.md)。
- **PDF 与分享**：通过 WebKit 生成保留文字的连续单页 PDF，经 Files 文档选择器交付；不是 A4 分页。Photos 保存图片、Files 保存文件和 `UIActivityViewController` 附件分享需分别验证，取消和拒绝权限不算交付成功。
- **输入边界**：iOS 没有供阅读翻页使用的公开音量键 API，音量键保留系统用途。外接键盘翻页已有专用接线，支持方向键、Page Up/Down、空格、Shift+空格和 Home/End；只在当前阅读页且未编辑、未打开覆盖层时处理，仍待真实键盘验收。
- **后台与通知**：系统朗读、AAC 录音、本地通知和轮询受 iOS 生命周期约束；没有配置 APNs，不保证应用挂起或退出后继续抓取消息。
- **待验收与发布**：Full/Lite 隔离、软件中文键盘与外接键盘、权限与音频中断、PDF 文件交付、数据库迁移及重启恢复均需对应环境验收。unsigned IPA 不能直接安装；证书、描述文件、正式签名和 App Store 发布尚未完成。

## Web

- **宿主**：Kotlin/Wasm 实验性静态站点，需支持 WebAssembly GC 的现代浏览器。完整资源与启动入口见 [浏览器版](../webApp/README.md)。构建成功不代表 GitHub Pages 已配置或部署。
- **账号与跨域**：知乎业务依赖单独安装并授权的具名油猴桥；它不是任意 URL 代理。Cookie、登录票据及上传凭据留在桥内。真实 Tampermonkey 会话的登录、写入和上传端到端路径尚未验收；图片跨域失败会影响展示与离线导出，不能承诺完整保存远程图片。
- **PDF**：通过浏览器打印界面，在浏览器支持时由用户选择“另存为 PDF”。正文保留文字排版；应用无法区分保存、打印或取消，也无法读取或直接分享用户另存的 PDF。提示“已打开打印界面”不是保存成功证明。
- **NLP**：ONNX Runtime Web 在独立 Worker 中按需加载，不预装模型。需安全上下文（HTTPS 或浏览器认可的本地入口）、Worker/WebAssembly、可用的 OPFS / IndexedDB / Web Locks / Cache Storage 与足够存储和内存；模型下载还受来源 CORS 约束。清理网站数据或浏览器回收存储可能需要重新下载，Worker 被终止后需重新加载模型。
- **通知范围**：保留页面可见时轮询。通知 Service Worker 只承接页面投递与点击恢复，没有离线 `fetch` 缓存或后台定时抓取。关闭标签页后不获取新通知；已显示的通知可重新打开应用。Web Push 需要额外常驻服务提供知乎账号事件，本项目不新增该后端；这不是浏览器缺少 Push API。
- **系统条件**：录音需要麦克风权限，文件分享需用户手势和浏览器 Web Share 文件支持，不支持时使用下载。后台节流、休眠和关页会影响朗读、录音与轮询。WebDAV 必须允许当前站点来源、方法和认证头的 CORS，远程地址使用 HTTPS。
- **待验收与部署**：浏览器 PDF 排版与打印、NLP 下载/推理/卸载、权限交互及账号桥仍待真实环境验收；AIGC 服务 CORS 和站点发布需各自完成部署，不能以客户端或服务源码代替线上结果。
