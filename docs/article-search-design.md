# 正文搜索

只支持 Compose 正文路径。搜索使用独立背景高亮，不显示选区手柄或菜单，不改变用户选择。

## 数据流

- 库从既有文字模型产生匹配，包含文档身份、稳定块/片段键和原始 UTF-16 区间；应用只持有查询、序号与面板状态。
- 使用真实命中行矩形和现有 `BringIntoViewRequester` 定位，不按全文字符比例估算。外部 `ScrollState` 仍由宿主唯一持有。
- 屏外惰性块按需布局后再定位；当前命中所需的块在关闭、改查询、取消或失败时释放，不全篇解除惰性布局。
- 全部匹配使用浅色背景，当前命中使用深色背景且不重复叠色。高亮与选择控制器独立，关闭搜索保留阅读位置。
- 宿主将实际顶栏、底部工具栏和朗读浮层的遮挡传给库的滚动策略。完全可见不动，部分可见靠最近边，屏外命中尝试居中；受文档边界限制，不保证始终居中。

## 匹配与状态

大小写不敏感的字面查询，归一化 Unicode 空白并保留偏移映射。同段行内格式不打断匹配，不跨逻辑段落拼词，不做图片 OCR，也不以公式源码代替渲染文本。

旧文档或查询结果不能定位到新正文。重复点击同一命中仍可重新定位；失败提示并允许重试。搜索提交和前后跳转隐藏键盘，用户选择手势取消当前搜索定位。

## 验证

复用现有测试，检查长单段、重复文字、屏外块和分栏中的实际命中行可见性；滚动数值改变本身不算通过。关闭搜索后，复制、段评、返回和回答切换保持原有行为。
