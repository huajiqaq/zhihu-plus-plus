# 正文搜索

从正文工具栏打开搜索，输入后用前后按钮循环跳转；定位失败可重试。只支持 Compose 正文，不支持 WebView。关闭搜索清除高亮，保留查询和阅读位置，不改变用户选区。

## 匹配与定位

- 使用渲染库的文字模型和匹配结果：大小写不敏感的字面查询，归一化 Unicode 空白并保留原始 UTF-16 偏移。同段行内格式不打断匹配，不跨逻辑段落，不做图片 OCR 或公式源码搜索。
- 全部命中浅色高亮，当前命中深色高亮，不重复叠色；与选择手柄和菜单独立。
- 用实际命中行几何和 `BringIntoViewRequester` 定位，宿主唯一持有 `ScrollState`，并提供顶栏、底栏和朗读浮层遮挡。完全可见不动，部分可见靠近边，屏外尝试居中，但受文档边界限制。
- 文档身份与稳定片段键隔离结果；旧查询不能回写新状态。同一命中可再次定位，提交及跳转隐藏键盘，用户选择手势取消当前定位。

应用面板状态见 `ArticleContentSearchState`，两种渲染器通过 `MarkdownSearchState` 接入；布局能力以实际渲染入口为准。
