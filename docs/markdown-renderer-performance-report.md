# Markdown 公式布局与回收

公式解析放到后台仍不足够：完整测量若留在 UI 线程，新公式进入视口会阻塞输入；离屏后丢失准备结果则会重复计算。单纯增加 `yield()` 不能移动同步测量。

采用受限后台准备、文档级 LRU 和递归惰性布局。缓存身份包含输入、字体和布局条件，活跃公式可固定；块回收后复用不可变准备结果和实测高度，脚注目标按需布局。

## 测量与验证

使用 [公式语料](../shared-domain/src/jvmTest/resources/zhihu-formula-corpus/formulas.json)，保持输入和滚动步长一致，测量到布局与绘制完成。截图回读的测试开销单独记录；平台、硬件或渲染路径变化后重新校准，不把单机结果换算成所有手机的门槛。

验证真实公式像素、行内尺寸更新、回收后重接、链接点击、长容器尾部、脚注往返及完整选区。依赖与补丁方式见 [依赖说明](markdown-library-dependency.md)。
