# 段评选区契约

喜欢或评论只作用于同一原始段落内可可靠映射的纯文本，允许单字。跨段、带格式或无法映射的范围不提交，并给出提示；复制和全选仍适用于全部可选择内容。

## 定位与请求

- HRM 使用 `MarkdownSelectionInfo.ranges`；提椠使用 `CjkSelectionState.selectedRanges` 与既有 Markdown 片段键映射。
- 原始选区必须只有一个正文段落范围，PID 存在、偏移有效，并与渲染文本一致。重复文字按实际区间定位，不取首次字符串匹配。
- 所选字符来自未格式化文本节点；已有段评高亮只是交互标注，不把加粗、链接、公式等洗成纯文本。转换时丢失格式信息的段落不能误判为纯文本。
- 通过校验后调用既有 `createSegmentReactions`，不增加服务器路径或字段。HTTP 失败、空响应和无授权不能报告成功；取消异常继续传播。

## 计数

评论增删按实际请求客户端和正文类型/ID 隔离。详情请求捕获累计增量水位，仅随成功正文发布；显示时叠加水位之后的增量，失败保留旧快照。成功才增减计数，普通评论不触发段评事件。

旧跨段 ID 一次操作只记首个 ID，读取去重。不猜测根评论删除的级联数量；没有服务端因果版本时不声称服务端强一致。

## 验证

复用已有同段、单字、重复文字和格式边界用例，核对真实原始偏移与请求。跨段、链接、图片、公式、代码等范围不发创建请求。获准使用真实页面时验证选区到请求结果和编辑器的链路，不自动发送评论。
