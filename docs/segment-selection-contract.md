# 段评选区契约

新建喜欢或段评要求同一原始段落内可可靠映射的纯文本，至少 5 个 UTF-16 单位（`String.length`，不是码点数）。不满足时不提交并提示；复制、全选及已有划线的喜欢/取消不受新建门槛限制。

## 定位与请求

- HRM 使用 `MarkdownSelectionInfo.ranges`；提椠使用 `CjkSelectionState.selectedRanges` 与稳定片段键映射。
- 显示块按转换器身份逐块校验连续性和文本，必须对应同一服务端 PID；多个显示块或换行不等于跨原始段落，不合并不同 PID 或独立同名 PID。
- 偏移为 UTF-16 半开区间，`br` 保留为 LF，重复文字按实际区间定位。原始段首 U+200B 对应段评中的 U+0020，保留等长偏移，不扩展为空白折叠、NBSP 归一化或任意零宽字符删除；未知嵌套分隔规则不猜测。
- 只接受未格式化文本节点；已有段评高亮是标注，不把加粗、链接、图片、公式或代码展平为纯文本，格式信息丢失时拒绝。已有划线展开到显示选区也须转换偏移。
- `createSegmentReactions` 的界面及请求入口均校验长度与定位。无授权、HTTP 失败或空响应不报告成功；传播取消异常，错误提示由正文页面持有，不随菜单关闭丢失。

## 已有划线

已有跨段 mark 不代表允许跨段新建。喜欢/取消及评论复用 `segment_id`，评论请求以 `segment.segment_id` 定位，不按引文重建或伪造单段坐标。引用按正文顺序连接真实切片，展示换行不计入原段偏移；打开已有评论不触发写操作。

## 计数

按实际请求客户端和正文类型/ID 隔离增量。详情捕获累计水位，成功正文发布后叠加后续增量，失败保留旧快照；请求成功才增减，普通评论不触发段评事件。旧跨段 ID 一次操作只记首个，读取去重；不猜测根评论删除级联数或宣称服务端强一致。
