# Markdown 完整文档与惰性布局

保留完整 AST，让脚注、图片列表和全局后处理从首帧就可用。只延迟屏外组合、测量与布局；列表、引用等大容器递归处理。块回收后沿用实测高度，避免滚动范围反复退回粗略估算。

首帧测量包含 HTML 转换、Compose 组合、布局和绘制，预热后用同一输入比较多次样本，不把进程启动混入渲染耗时。各阶段分别计时，不能因长文卡顿就先拆掉完整 AST。

脚注跳转按需布局目标块、注册 requester，完成后继续回收。文本选择和复制保持完整文档语义，不能把当前物化子树当成全文，也不能通过强制全量布局重新引入长文卡顿。

依赖与补丁方式见 [Markdown 依赖](markdown-library-dependency.md)。
